# RF Based Breast Cancer Abnormality Detection using Microstrip Patch Antenna

We as team ResonX are exploring antenna based microwave sensing for identifying differences between healthy and abnormal breast tissue conditions.

# How It Works
Antenna Simulation: Simulating antenna responses under different tissue conditions using CST Studio Suite.
RF Measurement: Measuring antenna responses using a Vector Network Analyzer (VNA).
Data Processing: Sending measurement data to an ESP32 for evaluating the results and presenting the output.
Embedded System: Programming the ESP32 using Arduino IDE.

# Technologies Used
CST Studio Suite
Vector Network Analyzer (VNA)
ESP32
Arduino IDE
